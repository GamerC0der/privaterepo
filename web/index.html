Kiosk OS — browser boot test

A from-scratch Linux ISO that boots straight into a fullscreen browser and runs nothing else, executed here by v86, an x86-to-WebAssembly emulator. No install, no server for the emulator itself.

Idle

Use the file picker when opening this page directly as file:// — browsers block fetch() of local files there.

The guest's NIC only reaches the outside world if you run a v86 network relay and point it here. Without one, the guest still boots and DHCPs, it just has nowhere to route to — this is a browser-sandbox limitation of any in-tab TCP/IP stack, not specific to this OS.
